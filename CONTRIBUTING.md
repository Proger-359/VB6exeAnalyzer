# Contributing

Thank you for your interest in this repository!

This repository is a **software archive** whose primary goal is to preserve and document an historical VB6 codebase. Because of this, the contribution policy is intentionally different from a typical active project.

---

## Project Status

This repository is maintained as a **historical and educational archive**.

The code represents a restored snapshot of an old project and is **not actively developed**.

The main goals are:

- Preservation

- Documentation about the codebase and internal methods

- Understanding of VB6 reverse engineering

---

## Code contributions are _not_ accepted

To preserve the integrity and historical accuracy of the archived source code, **pull requests that modify the code will not be accepted**, including:

- Bug fixes

- Refactoring

- New features

- Performance improvements

- Dependency changes

Even well-intentioned fixes are outside the scope of this repository.

If you would like to experiment, modernize, or fix the code, you shall **create a fork**.

You are encouraged to link your fork in an issue so others can discover it.

---

## Documentation contributions are welcome

Contributions that improve understanding of the project are highly appreciated.

You may submit pull requests for:

- Documentation improvements

- English translations or additional languages

- Clarifications about how the code works

- Technical explanations of VB6 behavior

- Discovered issues

- Reverse-engineering insights

- Diagrams, screenshots, examples, ...

In short: **anything that helps people understand the project without changing its behavior.**

---

## Documentation Guidelines

When contributing documentation:

- Keep technical accuracy in mind

- Prefer adding information rather than replacing existing text

- Clearly label hypotheses or uncertain details

- Write in clear and simple English

---

## Working on the code

This very repository intentionally remains a stable reference point. Previous commits can be used for better understanding of the codebase.

An official fork may come later to follow the roadmap.

---

## Thank you

Your help in documenting this project will be greatly appreciated.
