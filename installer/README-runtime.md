# VB6 Runtime requirements

This application requires the Visual Basic 6 runtime and OCX of common controls.

Required components:

- MSVBVM60.DLL (VB6 runtime)
- COMDLG32.OCX (Common Dialog)
- COMCTL32.OCX (Common Controls)
